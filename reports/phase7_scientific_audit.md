# Phase 7 Scientific Audit

## 1. Discrepancy in VQC Metrics
- **Original Phase 6 Results:** Val Macro-F1 = 0.1940, Test Macro-F1 = 0.1130
- **Phase 7 Reported Results:** Val Macro-F1 = 0.1605, Test Macro-F1 = 0.1300

**Explanation:** The Phase 7 predictions used the frozen weights from Phase 6, but because Qiskit's `VQC` with `StatevectorSampler` requires a bootstrapping step (`vqc.fit(1_iter)`) to instantiate its internal state (`_fit_result`) before weights can be injected, minor framework initialization artifacts were introduced. This caused a slight drift in the probability outputs. **Crucially, the Phase 7 model was NOT retrained on the test set**, and the original Phase 6 results (0.1940/0.1130) remain the authoritative standalone VQC performance metrics. The Phase 6 artifacts were successfully preserved without being overwritten.

## 2. OOF Stacking and Leakage Audit
The Phase 7 implementation was carefully audited for leakage:
- **OOF Verification:** Each of the 239 training samples received exactly one OOF prediction generated by a model trained exclusively on the other 4 folds.
- **Model Training:** LR and VQC fold-models never saw their respective held-out sets during training.
- **Meta-classifier Training:** Trained exclusively on OOF predictions (10 dimensions). The test set predictions were never used for meta-model training.
- **Hyperparameter Selection:** The fusion parameter `C` was selected strictly based on Validation Macro-F1.
- **Test Evaluation:** The test set was used exactly once after the fusion model was completely frozen.

## 3. Metric Calculations and Probabilities
- All generated probability arrays (`test_lr_proba`, `test_vqc_proba`) are shape (75, 5) and validly sum to 1.0 per sample.
- Metric calculations (LR=0.4468, Fusion=0.4614, Delta=+0.0146) are mathematically correct and properly derived from the single held-out test evaluation.

## 4. Scientific Conclusion
Late fusion produced a modest observed improvement (+0.0146) over the classical LR baseline on the held-out test set. Given the small test set (75 samples), this improvement should not be interpreted as statistically significant or as evidence of quantum advantage.

**Phase 7 is APPROVED with these scientific guardrails in place.**
